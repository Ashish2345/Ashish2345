### Currently building

**[Dafa](https://merodafa.com)** — legal and tax document intelligence. Statutes go
in as scanned PDFs; a navigable hierarchical index of the act comes out, queryable
in plain language, with every answer anchored to the exact clause it came from.

- Ingestion pipeline handling 600+ page statutes end to end — upload to queryable index
- OCR layer that routes per page: digital text extraction, Google Vision for scans
- LLM-built section tree over ~800K characters of statute markdown, chunked and reassembled
- Clause-level citation highlighting that maps each answer back to its source page region
